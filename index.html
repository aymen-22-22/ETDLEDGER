Platform

InfraLedger and Kubernetes, run with you

We install and operate InfraLedger with your team, and run isolated virtual Kubernetes clusters you can offer to customers or business units.

  • Installation, sizing and onboarding
  • An isolated virtual cluster per customer, with kubectl access
  • Design of the underlying Kubernetes infrastructure
  • Upgrades, capacity planning and incident support

Security

Security work, scoped to your environment

Detection, assessments and compliance work, on its own or alongside an InfraLedger deployment.

  • Detection rules and alert routing for deploy, access and configuration events
  • Penetration testing and configuration reviews, with findings ranked by risk
  • Controls and audit trails mapped to your auditors' framework

Our product

InfraLedger, the self-hosted cloud platform

We build InfraLedger: a platform where developers deploy apps and databases on your own servers, with every action recorded in an audit log.

  • Git and container deploys with automatic HTTPS
  • Managed PostgreSQL, MySQL, Redis and object storage
  • Runs on one Docker server or a Kubernetes cluster
  • Organizations, roles and a complete audit log
